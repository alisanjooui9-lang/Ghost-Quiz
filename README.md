🎮 حالت بازی

هر مسابقه شامل چند سؤال است.

کاربر یک دسته‌بندی را انتخاب می‌کند و سپس به سؤالات پاسخ می‌دهد.

پاسخ درست باعث دریافت XP و سکه می‌شود و پاسخ‌های اشتباه روی امتیاز تأثیر می‌گذارند.
